# Security policy

Author: Gavin Blacklock

Report a suspected vulnerability privately to the repository owner through GitHub's private vulnerability reporting, or by contacting the author through the contact route on the owner's GitHub profile.

In a report, name the affected component and the components you believe are unaffected. Incident communications for this programme follow the same rule: state which components are affected and which are verified unaffected.

Do not open a public issue for an unpatched vulnerability.
